# Dépendances et inspirations

Le code applicatif de Liasio est sous MIT. Cette licence ne remplace pas celles des dépendances. Les distributions installées conservent leurs métadonnées et notices de licence dans les environnements Python et les images de conteneurs.

Principales dépendances : Django, argon2-cffi, Gunicorn, WhiteNoise, Psycopg, PyOTP, cryptography, Segno, Pillow, markdown-it-py (et mdurl) et pypdfium2 (avec PDFium et ses notices tierces). Outils de développement : uv, pip-audit, Bandit et polib. Services déployés : PostgreSQL, Caddy, ClamAV et le moteur d’aperçus Liasio. Consultez les projets officiels et les métadonnées de la version verrouillée pour leurs conditions de redistribution.

Les icônes SVG, la marque textuelle et l’illustration CSS incluses ici ont été créées pour Liasio. Aucune police, photographie ou script tiers n’est chargé au fonctionnement.

Le lettrage du logo utilise Manrope, converti en tracés vectoriels. Sa licence SIL Open Font License est fournie dans [static/brand/Manrope-OFL.txt](static/brand/Manrope-OFL.txt) ; la police provient du [projet Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope). Le navigateur n’a pas besoin de charger une police pour afficher le logo.

[COMPARISON.md](docs/COMPARISON.md) cite Pingvin Share, ProjectSend, Gokapi et Send comme références fonctionnelles. Aucune partie de leur code ou de leurs éléments graphiques n’est distribuée dans ce dépôt.

# Dépendances et inspirations

Le code applicatif de LinkVault est sous MIT. Cette licence ne remplace pas celles des dépendances. Les distributions installées conservent leurs métadonnées et notices de licence dans les environnements Python et les images de conteneurs.

Principales dépendances : Django, argon2-cffi, Gunicorn, WhiteNoise, Psycopg, PyOTP, cryptography et Segno. Outils de développement : uv, pip-audit et Bandit. Services déployés : PostgreSQL, Caddy et ClamAV. Consultez les projets officiels et les métadonnées de la version verrouillée pour leurs conditions de redistribution.

Les icônes SVG, la marque textuelle et l’illustration CSS incluses ici ont été créées pour LinkVault. Aucune police, photographie ou script tiers n’est chargé au fonctionnement.

[COMPARISON.md](docs/COMPARISON.md) cite Pingvin Share, ProjectSend, Gokapi et Send comme références fonctionnelles. Aucune partie de leur code ou de leurs éléments graphiques n’est distribuée dans ce dépôt.
